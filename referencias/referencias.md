# Referencias de otras webs

Acá se registran las webs que nos gustan y **qué tomar de cada una**. Son inspiración de estructura, ritmo, jerarquía y estilo. **No se copian textos, imágenes, código ni la marca de nadie.** La identidad de Fedes manda: colores, tipografías y reglas están en `docs/07-identidad-visual.md`.

## Cómo agregar una referencia

1. Guardá capturas de pantalla en `referencias/capturas/`, con un nombre que diga qué son. Por ejemplo: `sitio-a-hero.png`, `sitio-a-casos.png`, `sitio-a-pagina-completa.png`.
2. Completá una ficha en este archivo con la plantilla de abajo.
3. Cuando arranque cada página, indicale a Claude Code qué referencias mirar: «para el Inicio, usá las referencias 1 y 3».

## Cómo usa Claude Code estas referencias

- Lee este archivo y mira las capturas de `referencias/capturas/` (puede leer imágenes por su ruta).
- Si tiene el navegador conectado, puede abrir la URL y mirar la página real, incluida su estructura y estilos.
- De cada referencia toma **solo lo que la ficha dice que tome** y respeta lo que dice que no copie.
- Ante la duda entre una referencia y los documentos de `/docs`, mandan los documentos de `/docs`.
